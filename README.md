# Amazon Sales Dashboard 📊

## 📌 Project Overview

This project is an interactive **Amazon Sales Dashboard** created using **Microsoft Power BI**.

The dashboard helps analyze sales performance and provides useful business insights through interactive charts, KPIs, and visualizations.

## 🛠️ Tools Used

* Microsoft Power BI
* Power Query
* DAX
* Data Visualization

## 📊 Dashboard

The dashboard provides insights into:

* Sales performance
* Sales trends
* Product performance
* Category-wise sales
* Key performance indicators (KPIs)
* Interactive filtering and analysis

## 🎯 Objective

The main objective of this project is to analyze Amazon sales data and transform it into an interactive Power BI dashboard that can help understand business performance and support data-driven decision making.
